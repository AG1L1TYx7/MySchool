# SmartSchool Design Documentation

**Status:** current as of 30 September 2026. This folder is the canonical design documentation for SmartSchool and the starting point of the rebuild.

## What SmartSchool is

An AI-native K-12 learning management system that runs entirely on local infrastructure. A conventional LMS (students, classes, assignments, grades, attendance, messaging, parents, gamification, multi-tenant SaaS administration) is paired with an AI service that uses local large language models through Ollama to tutor students, generate interactive H5P content, grade work, detect learning gaps and emotional state, and coordinate six autonomous agents.

## Reading order

New to the project: 01, then 02, then 07.
Building a feature: 02 for the behaviour, 06 for the routes, 03 for the tables, 04 if it crosses a service boundary.
Reviewing a design change: 05 first, then the affected section of 01.

## Conventions

- **Previous implementation** means the C# API (`SmartSchool.Api`) and Python AI service (`SmartSchool.AI`) in the old repository. **Target** means the Node.js LMS API in `apps/api`, which keeps the Python AI service as `apps/ai`.
- Route paths are written exactly as the previous code declared them, including inconsistent casing (`/api/Course`, `/api/v1/srs`). The target preserves them (ADR-010).
- Status labels in the feature catalog: **Real** (implemented and exercises the database or the LLM), **Partial** (works but with a documented gap), **Stub** (returns hard-coded data or throws). Every stub is listed so it is not ported by accident (ADR-008).
- Diagrams are Mermaid and render on GitHub and in most editors.

## Regenerating the endpoint inventory

The inventory needs the previous source. From a clone of the old repository:

```powershell
node docs/tools/extract-routes.cjs <clone>/SmartSchool.Api/Controllers <clone>/SmartSchool.AI/main.py > docs/06-ENDPOINT-INVENTORY.md
```

Summary counts, already verified on 30 September 2026: 77 controllers, 1,126 LMS routes (19 in three test controllers are dropped in the target); 155 AI service routes.
